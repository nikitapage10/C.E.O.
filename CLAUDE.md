# Working on C.E.O.

- **Deploys:** Vercel builds production from `main`. When a round of work is done and verified (typecheck, lint, unit tests, build), commit and push it to `main` as well as the working branch. The owner has asked for every finished change to go straight to production.
- **Checks:** `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`; `npm run test:e2e` for the browser tests (set `PLAYWRIGHT_CHROMIUM_PATH` to use a preinstalled Chromium).
- **Characters in-world:** the Syntherion know they live in a simulation but stay in the world of Ilyr. No jokes about code, GPUs or React. Pop-culture costumes are legally distinct, one per work, never the protagonist (Rocky is the exception).
- **Keep the lore in step with the world:** when you add or change a character model, costume, body, agent, pet or room, add it to the world lore in the same change: `lore/syntherion.md` (cast table, costumes, pets), the agent's dossier in `packages/simulator/src/lore.ts`, its bio, catchphrase and at least one relationship in `packages/simulator/src/cast.ts`, and a few lines in `packages/simulator/src/quips.ts`. Write them for the body they wear, and draw on the owner's favourites where it fits (Red Rising, Mass Effect, Pokémon, Baldur's Gate, Expedition 33, Project Hail Mary, Star Wars, Lord of the Rings, Nolan, melodic bass and 2000s emo).
- **Real agents:** whenever an agent goes real, update its Lattice room (driven by live data, demo dropped) and the Desk (cards and Systems) in the same round, and ship its lore.
- **Foundry:** the coding crew follows [docs/FOUNDRY.md](docs/FOUNDRY.md).
