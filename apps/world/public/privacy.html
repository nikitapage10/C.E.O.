Privacy

C.E.O. (Command Everything, Obviously) · last updated 28 November 2026

C.E.O. is a personal app built and used by one person, its owner. It isn't offered to the public, and nobody else can sign in to its private parts, which need the owner's passkey.

Google data it uses

  • Google Nest (Smart Device Management): reads the owner's thermostat (temperature, mode, setpoints) and changes it only when the owner asks.
  • Google Tasks: reads one task list the owner chooses, so quick-adds land on the kitchen list.
  • Gmail (when connected): reads the inbox read-only, so the owner can see who is waiting on a reply.
  • YouTube (when connected): uploads the owner's own show episodes to the owner's YouTube channel as Shorts. See below.

YouTube

C.E.O. uses the YouTube API Services to upload finished episodes of the owner's show to the owner's own YouTube channel. By using this feature you agree to be bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

  • What it asks for: one permission, https://www.googleapis.com/auth/youtube.upload (“Manage your YouTube videos”), which lets it upload a video and set its thumbnail. It can't read, edit or delete anything else on the channel, and it reads no channel or account information.
  • When it acts: only when the owner taps “Publish to YouTube” on an episode in the signed-in Studio desk. Nothing is uploaded automatically.
  • What it keeps: the YouTube video ID of each upload, the privacy status YouTube set, and when it happened, stored with the episode in the owner's private Azure storage. The video itself and its title, description and cover come from the owner's own show; nothing is read back from YouTube.
  • The sign-in token: Google's refresh token is encrypted on the server (sealed with a key held in Azure Key Vault) and stored in private Azure storage. It never reaches the browser, the public pages, the logs or the code repository.
  • Sharing: nothing obtained through the YouTube API Services is sold, shared with anyone, or used for advertising.
  • Revoking access: disconnect YouTube in the app's settings (Boiler Room > Controls > Connections), which revokes the token with Google and deletes it, or remove the app's access at any time from your Google Account's security settings: security.google.com/settings/security/permissions.
  • Deleting the data: disconnecting YouTube in the app deletes the stored token and the stored upload records (video IDs and privacy statuses) at once. If access is revoked from the Google Account instead, the app finds the token refused on its next use and the owner can delete the records by disconnecting; either way they are deleted within 30 days. The videos themselves stay on YouTube under the channel owner's control.

How it is kept

Google's sign-in tokens are sealed (encrypted) and stored in the owner's private Azure storage. The app's keys live in Azure Key Vault. Nothing from Google is put on the public pages, in logs, or in the code repository; the public pages show counts and states at most.

Sharing

Google data is never sold, shared with anyone, or used for advertising. It is used only to show the owner their own home and lists. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can disconnect Nest, Tasks, Gmail or YouTube from the app's settings at any time, which deletes the stored token, or remove the app's access from their Google Account's security settings at security.google.com/settings/security/permissions.

Contact

Questions about this policy go to the owner through the contact details on the app's Google consent screen.
