Privacy

C.E.O. (Command Everything, Obviously) · last updated 12 November 2026

C.E.O. is a personal app built and used by one person, its owner. It isn't offered to the public, and nobody else can sign in to its private parts, which need the owner's passkey.

Google data it uses

  • Google Nest (Smart Device Management): reads the owner's thermostat (temperature, mode, setpoints) and changes it only when the owner asks.
  • Google Tasks: reads one task list the owner chooses, so quick-adds land on the kitchen list.
  • Gmail (when connected): reads the inbox read-only, so the owner can see who is waiting on a reply.

How it is kept

Google's sign-in tokens are sealed (encrypted) and stored in the owner's private Azure storage. The app's keys live in Azure Key Vault. Nothing from Google is put on the public pages, in logs, or in the code repository; the public pages show counts and states at most.

Sharing

Google data is never sold, shared with anyone, or used for advertising. It is used only to show the owner their own home and lists. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can disconnect Nest, Tasks or Gmail from the app's settings at any time, which deletes the stored token, or remove the app's access from their Google Account's security settings.
